# 🚀 PROJETO 4

Uma lanchonete precisa saber o nome do prato e se o frete é grátis.

## Parte 1

```jsx
const opcao = 2
```

```
1 → Hambúrguer
2 → Pizza
3 → Suco
```

A variável `prato` deverá aparecer `Pizza`.

## Parte 2

```jsx
const subtotal = 120
```

A regra: subtotal de `100` ou mais tem frete grátis.

A variável `frete` deverá aparecer `Frete grátis` ou `Frete pago`.
